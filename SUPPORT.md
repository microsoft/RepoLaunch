# Support

Change2Task is a research software release.

Use [GitHub Issues](https://github.com/microsoft/RepoLaunch/issues) for:

- reproducible method or CLI bugs;
- schema and dataset integrity problems;
- documentation corrections;
- feature requests for new task families or construction backends.

Search existing issues before opening a new one. Include the Change2Task
version, operating system, Python version, command, and a minimal synthetic
reproduction. Do not attach proprietary repositories, credentials, private
task data, or model transcripts.

Microsoft Customer Service and Support does not provide a support contract for
this research project.
